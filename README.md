# The Shammakhi Chronicle

Personal CV website of **Muhannad Al Shammakhi**, Software Engineer — styled as an old newspaper.

Live: https://biotech-byte.github.io/

- Plain HTML, CSS and JavaScript — no build step
- English / Arabic (right-to-left) switch
- Day / night edition
- Filterable projects, downloadable CV, print-friendly layout

## Edit

- Text: `index.html` (English) and the `AR` dictionary in `script.js` (Arabic)
- Look: `styles.css`
- Photo and CV PDF: `assets/`

## Preview locally

```
node serve.cjs . 5180
```

Then open http://localhost:5180
